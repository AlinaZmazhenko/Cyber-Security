## About Me

Junior Cybersecurity / SOC Analyst with hands-on experience gained through practical labs and simulations focused on real-world SOC Tier 1 tasks.

I am a detail-oriented Cybersecurity Analyst and Digital Forensics enthusiast with a strong technical foundation in incident response, log analysis, and network security monitoring. 
My hands-on experience, documented through extensive lab work, spans from investigating complex web attacks and RCE vulnerabilities to performing deep-dive post-exploitation forensics on Linux and Windows endpoints.
I specialize in dissecting system logs, identifying unauthorized persistence mechanisms like malicious systemd services or backdoored accounts, and auditing suspicious system activity using tools like auditd,

environments against modern cyber threats.
