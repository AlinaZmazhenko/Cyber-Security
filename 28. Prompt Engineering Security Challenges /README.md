Prompt Engineering Security Challenges

A practical project focused on designing and evaluating prompts for cybersecurity-related tasks.
The assignment explores several prompt engineering techniques and demonstrates their application in security analysis scenarios.

Objectives
explore core prompt engineering techniques;
apply prompting strategies to cybersecurity tasks;
evaluate how prompt structure affects model performance;
compare the effectiveness of different prompting methods.
Implemented Techniques
1. Zero-shot Prompting

Classification of security logs as malicious or benign without providing prior examples.

2. Prompt Templates

Development of a reusable template for extracting Indicators of Compromise (IOCs) from security alerts using placeholders.

3. Few-shot Prompting

Detection of SQL injection vulnerabilities using multiple secure and insecure code examples.

4. Chain-of-Thought (CoT)

Step-by-step phishing email analysis with reasoning based on suspicious indicators.

5. One-shot Prompting

Extraction of IP addresses from network logs using a single demonstration example.
